# 德微科技：功率半導體產業與財務分析

### 從垂直整合的商業邏輯，走到獲利品質與投資現金流

[English](README.en.md) · [產業與策略](docs/industry-analysis.zh-TW.md) · [財務分析](docs/financial-analysis.zh-TW.md) · [資本預算](docs/capital-budgeting.zh-TW.md) · [來源](docs/sources.md)

**一家二極體廠向上游晶圓製造整合，能否把車用、工控與伺服器的需求機會，轉化成可持續的投資報酬？**

本專案以德微科技（ERIS Technology，3675）與基隆晶圓製造業務整合為個案，結合功率半導體價值鏈、2019–2023 年合併財報、營運資金及資本預算分析。材料來自本人共同參與的 Financial Management 小組分析，公開版於 2026 年重新整理，並對照官方年報核對關鍵數字。

> **核心判斷：** 垂直整合增加製程與供應協調能力，也帶來設備、產能利用與資金需求。判斷價值創造，需要同時檢查產品組合、固定成本吸收、營業性現金流與投入資本。

## 分析的三項發現

| 問題 | 數據與判斷 | 管理意涵 |
|---|---|---|
| 毛利率上升，獲利是否同步改善？ | 2023 年毛利率 **37.54%**，高於 2022 年 **36.94%**；營收減少 **20.13%**，營業利益減少 **28.04%** | 產品組合與成本效果須分開；毛利率改善仍可能伴隨規模收縮及費用吸收壓力 |
| 技術投入與償債能力如何一起評估？ | 2023 年研發費用增約 **2.40%**，研發費用率升至 **7.96%**；流動比率約 **1.20 倍**、速動比率 **0.96 倍** | 研發占比上升部分來自營收分母下降；需保留轉型投資與日常資金緩衝 |
| 正 NPV 是否足以支持併購？ | 工作表選定現金流代理值重折現為 **119,714 仟元**；簡報另列 **175,229 仟元**，版本未對齊 | 須先確認專案增量、資本支出、營業性營運資金與折現率；兩個數字均不能當作已驗證併購價值 |

## 產業知識如何改變分析方法

- **界定功率與保護元件的角色：** AI 伺服器需求需連到電源轉換、保護元件與客戶設計導入，不能直接套用 GPU 或先進邏輯晶片的成長率。
- **拆解垂直整合的取捨：** 設計、晶圓與封測協同可能縮短導入時間；設備支出、製程轉換及低稼動率也會影響報酬。晶圓尺寸擴大要連到可售良品成本，而非只比較面積。
- **選擇合理的比較基礎：** 強茂（PANJIT）較接近分離式元件情境；台積電適合提供產業背景，跨商業模式的毛利率排名不足以證明競爭優勢。
- **把需求敘事轉成驗證條件：** 車用與工控成長須追蹤認證、導入、良率、訂單與回款，應用占比目標也須與實績分開。

## 重算

僅需 Python 3 標準函式庫，無外部服務或金鑰：

```bash
python3 scripts/reproduce_analysis.py
python3 scripts/reproduce_analysis.py --check
```

第一個指令產生歷史指標、來源模型折現診斷與敏感度。第二個指令核對財報勾稽、比率及已保存輸出。[計算結果](outputs/analysis.md) · [計算程式](scripts/reproduce_analysis.py)
