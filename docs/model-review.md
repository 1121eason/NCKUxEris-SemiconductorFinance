# 原稿、試算表與公開版的差異

[首頁](../README.md) · [12 項審閱登錄](../data/review-findings.csv) · [來源](sources.md)

原始檔不修改。本文件記錄公開版使用的數據與方法判斷；程式只能檢查已轉錄資料的數學一致性，不能取代財報審計或實際專案驗證。

| 項目 | 核對結果與處理 |
|---|---|
| 公司成立年份 | G2 p.4 為 1999，官方公司簡介為 1995；公開版採官方資料 |
| 2023 年淨利 | G3 Working Paper H13:H15 為業外 −17,576、所得稅費用 38,041、淨利 255,885；官方合併為業外 −10,905、所得稅利益 37,195、淨利 337,792 |
| 應收週轉率 | G3 財務分析 K9 為 5，官方為 4.51；公開歷史表使用 4.51 |
| EPS | 原表含整數四捨五入；官方五年比較表採追溯調整，公開版保留其精度與調整口徑 |
| Beta | G3 參考頁 C3、G5 寫明寶雅，隱藏範例亦出現該公司；沒有把此範例當作德微 Beta。G1 p.55 圖的底層序列未另取得 |
| WACC | Working Paper AD4、AD5 成本欄空白，AD7 固定 2.2%；權重以帳面總負債與權益計算。原簡報另有市場價值圖，不能視為已與工作表連結 |
| NPV 版本 | G1 pp.60–61 為 175,229，G3 AE13 快取 119,713.527；公開版分別標示，不挑選較高者作結論 |
| 增量現金流 | I36:M36 以公司收入乘車用占比；W22:AA22 使用依占比調整的獲利與公司層級 D&A／營運資金，仍非完整有／無專案差額 |
| 資本支出與營運資金 | W11:AA11 沒有扣除後續 CapEx，流動資產減流動負債混入現金與融資項目；此代理值不能直接定義為 FCFF |
| 應用組合 | G1 pp.47–48、G3 G28:I32 將半年度公司說明、年度模型及未來目標混用；公開版不當成已審計年度占比 |
| 同業比較 | 不同規模、業務與可能期間混合；G2 p.16 的台亞淨利符號與 p.52 衝突。公開版保留比較方法，未沿用未同步核對排名 |
| 預測與實作差異 | 2024 Q4 是估計，2025–2028 是預測；G1 pp.50–51 的 D&A 隨營收成長說法與 G3 W5:AA5 的移動平均公式不同 |

## 可重算與不可由本次重算證明的內容

**已核對：** 指定兩份 PDF 的內容、選定工作表公式與快取、官方年報相關頁面；公開歷史資料之資產負債勾稽、損益勾稽、部分比率、來源代理現金流折現與敏感度。

**未執行：** 原 Excel／Sheets 全工作簿的原生重算、德微 Beta 報酬序列重估、完整同業報表重新建表、真實專案增量 FCFF、最終交易現金支出與綜效查證。

Google Sheets 提供原始資料快照，未修改線上檔。原 PDF 的影像圖表已做視覺抽查，公開圖表由核對資料重新繪製。資料來源與版本在 [sources.md](sources.md) 中逐一列明。
