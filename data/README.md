# 資料定義與口徑

全部金額為 **新台幣仟元**，EPS 為元／股。期間為曆年 2019–2023，採德微 2023 年年報的**合併**口徑。資料於 2026-10-28 人工核對，未加入後來實績來改寫原預測。

| 檔案 | 來源與用途 |
|---|---|
| `historical-financials.csv` | 官方年報 PDF p.64／印刷 p.60 研發、PDF p.74／印刷 p.70 資產負債、PDF p.76／印刷 p.72 損益；COGS 與營業費用由相同表中小計相減，2022–2023 另對照 PDF p.82 |
| `reported-ratios.csv` | 同年報 PDF p.78／印刷 p.74；保留官方公布比率與平均日數 |
| `source-model-diagnostic.json` | 指定 Google Sheets 匯出快照中 Working Paper 的選定快取數值、公式與位置，供折現重算及模型診斷；不代表已驗證的專案現金流 |
| `review-findings.csv` | 原稿、工作表與官方來源之間的差異登錄 |

重要欄位：`net_profit` 包含非控制權益，`net_profit_parent` 僅歸屬母公司業主；兩者在早期年度不同。`total_equity` 包含非控制權益，與負債加總對應資產。`tax_expense_signed` 正數為費用、負數為利益，因此淨利 = 稅前淨利 − 此欄位。2023 年稅前 300,597 加所得稅利益 37,195 得淨利 337,792。

`eps_restated` 使用年報五年比較表的追溯調整口徑。例如 2022 年 9.08 與未調整的 10.26 不同。ROE 採年報公布值，未以期末權益自行取代平均權益。

輸出中的毛利率、營益率、淨利率、研發費用率均由金額重算。比率檔中百分比以 37.54 代表 37.54%，腳本計算則使用小數。流動比率 119.85% 約等於 1.20 倍。

現金循環天數為 **365 / 應收週轉 + 365 / 存貨週轉 − 365 / 應付週轉** 的近似推算，採已四捨五入的官方週轉率，不等同公司逐筆收付款天數。帳面淨營運資金 = 流動資產 − 流動負債，與估值所需排除現金、融資負債的營業性淨營運資金不同。

原始工作簿包含其他公司教學範例與隱藏分頁，不公開整份工作簿。主圖與公開財務表使用已核對資料，不採用來源錯誤的 2023 年淨利。來源模型診斷刻意保留原始快取值，避免把修正後資料冒充原模型。
